<h1 align="center"><img src="https://raw.githubusercontent.com/superdarco78/okno-ha-integracja/main/custom_components/okno_ha/brand/icon.png" height="44" align="absmiddle"> Okno HA (HA Window) – intégration</h1>

<p align="center">Chaque fenêtre avec store est un <b>appareil</b> dans Home Assistant. Un assistant avec 7 cercles et des images, les changements via <b>Configurer</b>, la carte ajoutée toute seule au tableau de bord, la carte Okno HA incluse.</p>

> ℹ️ Fonctionne avec tout moteur de store dans Home Assistant (`cover.*`) : Zigbee, Z-Wave, Tuya, Shelly, Somfy et d’autres. Fenêtres à un ou deux vantaux.

<a name="automatyzacje"></a>
<h2><a name="j104" href="#j104"><img src="https://raw.githubusercontent.com/superdarco78/okno-ha-integracja/main/img/kroki6/fr/h-automatyzacje.svg" height="48" alt="La fenêtre dans les automatisations"></a></h2>

La fenêtre est un volet normal dans HA. Dans une automatisation, choisissez **Volet : définir la position** (ou ouvrir / fermer) et l’entité fenêtre, par ex. **Okno Salon**. Les deux stores des vantaux bougent ensemble.

<a name="karta-w-srodku"></a>
<h2><a name="j105" href="#j105"><img src="https://raw.githubusercontent.com/superdarco78/okno-ha-integracja/main/img/kroki6/fr/h-karta-w-srodku.svg" height="48" alt="La carte Okno HA incluse"></a></h2>

L’intégration contient la carte Okno HA. Pas d’installation séparée ni de ressource. Apparence claire et sombre, météo derrière la vitre, jour et nuit.

<p align="center"><picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/z3/animacja-ciemna-en.webp"><img src="https://raw.githubusercontent.com/superdarco78/roleta-realistyczna/main/img/z3/animacja-en.webp" width="70%" alt="Animation de la carte Okno HA"></picture><br>

Documentation complète de la carte (éditeur, toutes les options, exemples): [superdarco78/roleta-realistyczna](https://github.com/superdarco78/roleta-realistyczna/blob/main/README_EN.md).

> ℹ️ Vous avez déjà la carte Okno HA depuis HACS ? Pas de souci. Les deux peuvent être installées.

<a name="recznie"></a>
<h2><a name="j106" href="#j106"><img src="https://raw.githubusercontent.com/superdarco78/okno-ha-integracja/main/img/kroki6/fr/h-recznie.svg" height="48" alt="Installation sans HACS (manuelle)"></a></h2>

1. Téléchargez la [dernière version](https://github.com/superdarco78/okno-ha-integracja/releases/latest) (Source code, zip).
2. Copiez le dossier `custom_components/okno_ha` dans `config/custom_components/` de HA (par ex. avec le module **File editor** ou **Samba**).
3. Redémarrez HA et cliquez sur **Ajouter une intégration** (étape 5 de l’installation).

<a name="usuwanie"></a>
<h2><a name="j107" href="#j107"><img src="https://raw.githubusercontent.com/superdarco78/okno-ha-integracja/main/img/kroki6/fr/h-usuwanie.svg" height="48" alt="Suppression"></a></h2>

Une fenêtre : **Paramètres → Appareils et services → Okno HA**, à côté de la fenêtre **⋮ → Supprimer**. Toute l’intégration : supprimez toutes les fenêtres, puis dans HACS **⋮ → Retirer** et redémarrez HA. Vos vrais stores restent inchangés.
